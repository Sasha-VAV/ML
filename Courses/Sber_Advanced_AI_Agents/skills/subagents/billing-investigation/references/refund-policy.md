# Учебная политика возврата

Для возврата создаётся точное предложение с `payment_id`, суммой и версией. Доверенная исполняющая среда выполняет действие только после подтверждения, связанного именно с этим предложением. Изменение суммы или версии требует нового подтверждения.

Этот файл — учебный ресурс навыка. Он не является источником актуальных продуктовых правил; сетевой инструмент `billing_policy` возвращает проверяемое правило для текущего запуска.
