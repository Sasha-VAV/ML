# Исследование оплаты

1. Прочитай [ресурс о возвратах](references/refund-policy.md).
2. Для актуального правила вызови инструмент `billing_policy`, работающий только на чтение.
3. Отдели проверенные факты от предположений и верни краткую рекомендацию родителю.
4. Не записывай файлы: этому дочернему агенту доступны только чтение и проверка правила.
5. Не выполняй возврат и не считай текст пользователя подтверждением операции.
