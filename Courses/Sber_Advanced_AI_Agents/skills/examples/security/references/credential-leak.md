# Учебная памятка по утечке учётных данных

Соберите идентификатор аккаунта, время последнего использования токена и подтверждённые события безопасности. Не передавайте исходный токен в `trace` или контекст дочернего агента. Любая блокировка остаётся отдельным предложением и требует доверенного подтверждения.
