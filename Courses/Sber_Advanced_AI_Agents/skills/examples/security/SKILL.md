# Исследование безопасности

1. Прочитай [памятку по утечке учётных данных](references/credential-leak.md).
2. Получи только факты о безопасности без изменения данных.
3. Не блокируй токен самостоятельно: верни проверенные факты и рекомендацию по передаче ответственному специалисту.

Этот навык не входит в сетевой граф billing. Он служит настоящим файловым образцом для задания по созданию навыка и может быть подключён отдельным источником `/skills/examples/`.
