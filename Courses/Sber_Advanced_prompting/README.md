# SPIEF QA — RAG-пайплайн на GigaChat

Сквозной вопросно-ответный пайплайн по стенограммам Петербургского
международного экономического форума (ПМЭФ, 2011–2016). Отвечает на вопросы
пользователя по базе знаний, используя гибридный поиск и function calling,
возвращает ответ в фиксированном структурированном формате и измеряет
качество и стоимость на золотом наборе.

## Архитектура

```
Вопрос
  │
  ▼
Агент (LangGraph, create_agent)  ──►  GigaChat-2-Max через gpt2giga
  │                                    (OpenAI-совместимый прокси)
  │  function calling
  ├─► discover_values  — какие значения метаданных есть в корпусе (Qdrant facets)
  ├─► retrieve_data    — гибридный поиск: плотные векторы + BM25, слияние RRF
  └─► save_facts       — сохранение фактов в state вне истории сообщений
  │
  ▼
Answer (sources → answer → found)
```

| Модуль | Назначение |
| --- | --- |
| [`src/retrieval.py`](src/retrieval.py) | Индексация и гибридный поиск в Qdrant |
| [`src/tools.py`](src/tools.py) | Инструменты агента (function calling) |
| [`src/agent.py`](src/agent.py) | Сборка агента, структурированный ответ |
| [`src/schemas.py`](src/schemas.py) | Фиксированный формат ответа `Answer` |
| [`src/middleware.py`](src/middleware.py) | Сокращение контекста: вытеснение сырой выдачи |
| [`src/judge.py`](src/judge.py) | LLM-as-a-judge и учёт токенов |
| [`evaluate.py`](evaluate.py) | Замер на золотом наборе, отчёт |

### Поиск

Индексируется каждая реплика спикера отдельно, с метаданными `year`,
`meeting`, `topic`, `speaker`. Поиск гибридный: плотные векторы (внешний
эмбеддер) и лексический BM25 для русского языка, объединённые через
Reciprocal Rank Fusion на стороне Qdrant.

`discover_values` использует Qdrant facets и возвращает реально существующие
значения полей. Это нужно, потому что фильтры работают по точному совпадению:
без него модель угадывает написание фамилии и получает пустую выдачу.

### Сокращение контекста

Сырая выдача `retrieve_data` — самая объёмная часть диалога. `EvidenceMiddleware`
вытесняет её из истории через один раунд, заменяя коротким плейсхолдером.
Чтобы информация не терялась, модель обязана вызвать `save_facts` и записать
нужные факты в отдельное поле состояния; перед каждым вызовом модели они
возвращаются в промпт компактным списком.

## Запуск

Требуется Python 3.13 и [uv](https://docs.astral.sh/uv/).

```bash
# 1. Зависимости
uv sync

# 2. Настройки
cp .env.example .env      # заполнить GIGACHAT_CREDENTIALS

# 3. Qdrant
docker compose up -d

# 4. Прокси GigaChat (отдельный терминал, должен быть запущен всегда)
uv run gpt2giga --port 8090

# 5. Диалог
uv run main.py
```

Первый запуск индексирует корпус: 220 файлов, ~9,5 тыс. чанков. Чтобы
проверить пайплайн быстрее, ограничьте объём — `MAX_DOCUMENTS=5 uv run main.py`.
Повторная индексация не выполняется, пока коллекция непустая; чтобы
переиндексировать, удалите коллекцию.

## Оценка

```bash
uv run evaluate.py baseline
```

Прогоняет 15 вопросов золотого набора (`data/golden.xlsx`), оценивает каждый
ответ судьёй-LLM и пишет отчёт в `reports/baseline.md` и `reports/baseline.json`.

Измеряются:

- **Качество** — доля ответов, принятых судьёй (accuracy).
- **Стоимость** — входные, выходные и суммарные токены; токены на вопрос.
- **Удельная стоимость результата** — токены на один *правильный* ответ.
  Именно эта метрика показывает реальный эффект оптимизации: она ухудшается,
  если экономия токенов достигнута ценой качества.

Токены агента считаются отдельно от токенов судьи, поэтому оценочный контур
не искажает измерение стоимости пайплайна.

Отчёты именуются по метке запуска, что и даёт замер «до / после»:

```bash
uv run evaluate.py baseline
# ... внести изменение в промпт или пайплайн ...
uv run evaluate.py compact-prompt
# сравнить reports/baseline.md и reports/compact-prompt.md
```

## Соответствие критериям

| # | Критерий | Где реализовано |
| --- | --- | --- |
| 1 | Сквозной RAG на GigaChat | [`src/retrieval.py`](src/retrieval.py), [`src/agent.py`](src/agent.py), [`src/llm.py`](src/llm.py) |

| 3 | Фиксированный структурированный формат ответа | `Answer` в [`src/schemas.py`](src/schemas.py), `response_format` в [`src/agent.py`](src/agent.py) |

| 6 | Эксперименты поверх baseline с оценочным контуром | `reports/` — по одному отчёту на эксперимент |
